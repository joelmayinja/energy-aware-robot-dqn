Compact policy

11,481 parameters (about 8.26× smaller). Held-out result: 6/50 targets reached (12%). Compactness is demonstrated; task performance needs more work.

About this experiment

Interpret results in context

The IK-assisted DQN is initialized from inverse-kinematics demonstrations. The baseline follows each target with fixed-speed inverse kinematics under the same buffer model. Current held-out results show target reaching but no verified energy savings; compare energy only when both policies complete the same seeded target. The robot pose is an angle-based 2D schematic, not a PyBullet camera render. Grid-fault scenarios and Raspberry Pi execution remain future work.
