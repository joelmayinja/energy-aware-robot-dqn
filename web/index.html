About this experiment

Interpret results in context

The baseline follows each target with inverse kinematics and maximum joint speed in the same seeded simulation. DQN actions are discrete velocity commands. The robot pose is an angle-based 2D schematic, not a PyBullet camera render. The dataset calibration, distillation, grid-fault scenarios, and Raspberry Pi/ONNX execution are planned stages, not currently implemented.
